# HuellApp - Backend API REST (Etapa 3)

## Descripción
API REST en Node.js y Express para la App HuellApp. Base de datos conectada en MongoDB Atlas.

## Instalación y Ejecución
1. Ejecutar: `npm install`
2. Crear un archivo `.env` con: `PORT=3000` y tu `MONGODB_URI`
3. Encender el servidor con: `npm run dev`

## Pruebas
En la raíz del proyecto está el archivo `HuellApp_API.postman_collection.json` listo para importar en Postman.
